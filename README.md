# Nasz dom

Wspólna aplikacja domowa: wydatki i rozliczenia, listy zakupów ze spiżarnią i kartami, menu z przepisami, grafik pracy z wypłatą, kot, obowiązki, liściki, prąd i gwarancje.

- Działa w przeglądarce i po dodaniu do ekranu głównego iPhone'a (PWA), także bez internetu.
- Synchronizacja na żywo przez Supabase (`supabase/schema.sql`).
- Bez kroku budowania: Preact + htm w `app/vendor`.

Jak uruchomić: zobacz [INSTRUKCJA.md](INSTRUKCJA.md).
